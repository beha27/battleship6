# ⚔️ Морской Бой 10×10 (4 Корабля) — Ручная расстановка & PvP по Wi-Fi

Актуальная версия браузерной игры «Морской бой» 10×10 с ручной расстановкой флота, локальным PvP-режимом по Wi-Fi и информативным статусом выстрелов («Попадание» vs «Корабль уничтожен»).

## 🚀 Комплектация флота:
Каждый игрок расставляет ровно **4 корабля** (по 1 штуке):
1. 🛳️ **1× 4-палубный** (Линкор)
2. 🛳️ **1× 3-палубный** (Крейсер)
3. 🛳️ **1× 2-палубный** (Эсминец)
4. 🛳️ **1× 1-палубный** (Катер)

## 🎮 Ключевые возможности:
- **📐 Поле 10×10**: Классическое полноразмерное поле.
- **🎯 Уведомления об уничтожении**: Игра различает обычное ранение палубы (`💥 Попадание!`) и полное затопление корабля (`🔥 Корабль уничтожен!`), помечая убитый корабль крестиком (`❌`) на темно-красном фоне и автоматически закрывая его контур точками.
- **🚢 Удобная расстановка**: 
  - Ручная установка с разворотом (Горизонтально / Вертикально).
  - Автоматическая проверка правила 1 свободной клетки вокруг кораблей.
  - Кнопка **«🎲 Авто-расстановка»** для моментального размещения.
- **📡 PvP Режим по Wi-Fi**: Игра на двух устройствах через P2P (PeerJS) без стороннего сервера.
- **🤖 PvE Режим**: Бой против бота.
- **🔄 Защита от случайных сбросов**: Кнопки «Реванш» и «В меню» открываются только после финала матча.
